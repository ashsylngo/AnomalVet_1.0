# AnomalVet demo script

1. **Splash**: logo and simulated start-up checklist. Skip with a tap or key.
2. **Home**: three cages. C2 is at Watch with one open anomaly (low activity, PIG-C2-04) and a report suggestion. Open **View pigs**.
3. **Demo tools > Anomaly in a cage** (C2): within about 20 s the status moves to Alert and a new anomaly appears.
4. **Prepare report**: the Report tab opens prefilled. Review, press **Send report (simulated)**, confirm, watch Queued, Sent, Delivered (all labeled Simulated). See it under Sent reports.
5. **Cages**: pick a cage, see the camera placeholder, readings with age, anomalies and the 24-hour trend with threshold lines.
6. **Demo tools > Make Stale / Make Offline / Restore**: badges change (icon plus text). **Camera lost** switches the placeholder to "No camera signal".
7. **Back to normal**: readings recover, the anomaly resolves, a follow-up report is suggested.
8. **Vet**: clinic and store cards (all placeholders).
9. **Loading and error states** via the delay slider and error toggle. **Reset demo** restores the seed.

Thresholds are defaults pending veterinary confirmation. Nothing in the app is a diagnosis.
